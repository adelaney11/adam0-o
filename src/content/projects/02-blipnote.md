An iMessage extension built with AVFoundation and AudioKit: capture a voice
note, run it through real-time effects and text-to-speech, and send it back as
an animated, hand-drawn transcription. The trembling "boiling" line animation —
3 jittered variants cycled at 10fps — is the same effect you can scribble with
using the ✎ button up in the corner.
